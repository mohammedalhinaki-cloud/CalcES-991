# تقرير القبول — المرحلة السابعة

هذه المراجعة لنسخة React + TypeScript التي يبدأ تشغيلها من `src/main.tsx`، وليس ملفات JavaScript القديمة أو موقع `site/`. كانت مراجعة المرحلة السابعة محلية؛ نُشرت المخرجات لاحقًا بطلب المستخدم كما هو موثق أدناه.

## نتيجة التشغيل النهائي

| الفحص | النتيجة |
| --- | --- |
| Vitest | 113 اختبارًا ناجحًا في 9 ملفات |
| TypeScript | ناجح دون أخطاء |
| Vite production build | ناجح؛ يبقى تحذير حجم الحزم |
| Playwright على نسخة الإنتاج | 24 اختبارًا ناجحًا، دون تجاوز اختبارات |
| أخطاء المتصفح والموارد | لم ترصدها فحوص التشغيل المحددة أدناه |

المجموعة الكاملة شُغلت بواسطة `npm run test:e2e:production` بعد الإصلاح، بما فيها الاختبار المخصص لملفات الإنتاج. الاختبارات القديمة المنفصلة بـ`test:legacy` ليست ضمن هذه الأعداد.

## إعادة إجراء الفحص

```sh
npm ci
npm test
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e:production
```

يمكن حذف متغير المسار عند تثبيت متصفح Playwright بواسطة `npx playwright install chromium`. أمر الإنتاج يشغل فحص TypeScript والبناء ثم جميع تدفقات المتصفح على المخرجات المبنية، وليس خادم التطوير. يجب إتاحة المنفذ 5174.

## العيب الذي أصلحته هذه المرحلة

كان تكامل `abs(x−0.3)` على [0,1] يُرفض عند نفاد عمق التقسيم رغم أن الدالة مستمرة. زيد العمق من 20 إلى 32 مع الحفاظ على حد 20000 تقييم، والتسامح المطلق والنسبي 1e−10، والتحقق النهائي من مجموع تقديرات الخطأ، ومهلة العامل. الاختبار يقارن القيمة بـ0.29 ضمن 1e−9. تستمر اختبارات رفض العينات غير الحقيقية أو غير المنتهية.

المقارنات العددية للتكامل لا تشترط تطابق آخر منزلة من نص مقرب إلى 14 رقمًا؛ تستخدم المرجع التحليلي والتسامح المعلن. اختبارات التنسيق منفصلة.

## حدود النتيجة

- الاختبارات على Chromium، بما فيه محاكاة هاتف؛ لم تُجر مراجعة على هاتف فعلي أو Safari أو Firefox.
- لا تدعي الواجهة تطابقًا بصريًا بكسليًا مع الجهاز الأصلي، أو تنفيذ جميع وظائف جهاز Casio. النطاق هو الوظائف المتفق عليها والموثقة في README.
- BigNumber بدقة 64 رقمًا لا يضمن دقة مطلقة لكل عملية. المركبات وكثيرات الحدود بدقة الآلة، وللتكامل والجذور قيود مجال وتقارب موضحة في README.
- يبقى تحذير Vite للحزم الأكبر من 500kB. لم يقس هذا الفحص التحميل على شبكات ضعيفة، ولا يتضمن اختبار أداء شاملًا.
- السجل والذاكرة خلال الجلسة فقط. إعادة تحميل الصفحة تعيد الحالة الابتدائية عمدًا.
- لا يغطي فحص النشر إعدادات الحساب العامة أو اختبارات تحميل واسعة النطاق.

## تحديث التخطيط والمشاركة والتثبيت

- التخطيط الجديد يعتمد الشاشة الفاتحة والخلفية المنقطة والأزرار الداكنة وSHIFT الأصفر وALPHA البنفسجي، مع مساحة محجوزة أعلى الشاشة لإعلان مستقبلي دون إضافة خدمة إعلانات.
- لم تعد مساحة العمل ظاهرة تحت الحاسبة؛ تُفتح بزر «الأدوات»، أو عند اختيار وظيفة متقدمة، وتُطوى دون فقد الخلايا أو اتصال زر = بالنموذج.
- أضيفت مشاركة الجهاز وبديل نسخ الرابط والعرض اليدوي، مع معالجة إلغاء المستخدم. أضيف تثبيت PWA وشرح خطوات التثبيت اليدوي للمتصفحات التي لا توفر نافذته.
- نجحت اختبارات الوحدات الـ113. أصبحت مجموعة المتصفح 30 حالة بعد إضافة ست حالات للمشاركة والتثبيت وطي الأدوات والتشغيل دون اتصال، واجتازت الحالات المضافة الفحص مع الحالات السابقة.
- فحص CDP داخل ملف Chromium شخصي دائم على نسخة الإنتاج المحلية أعطى `installabilityErrors: []`. الاختبارات المعزولة تتجاهل منع التثبيت في وضع التصفح الخاص فقط، ولا تتجاهل أخطاء تعريف التطبيق. لم ينفذ تثبيت فعلي على هاتف شخصي.
- أصلح تحذير MathLive دون اتصال بإعطاء `fontsDirectory` عنوانًا مطلقًا محليًا، فيتجنب طلب HEAD الاستكشافي عند تحميل الخطوط.
- عامل الخدمة المولد من محتوى الإنتاج يخزن 33 موردًا محليًا، بما فيها الخطوط وعامل الحساب. نجح التكامل بعد إعادة تحميل الحاسبة دون اتصال بعد اكتمال تهيئة التخزين.
