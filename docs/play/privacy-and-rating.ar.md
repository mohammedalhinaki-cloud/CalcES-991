# نافذة التعريف والخصوصية وتذكير التقييم

زر الدرع الحالي «الخصوصية» في Android يفتح نافذة عربية بعنوان «عن التطبيق والخصوصية»، مع الإصدار وMaaoun Studio والدعم `jy906675@gmail.com` وشروط الاستخدام. لم نضف زرًا جديدًا إلى شريط الأدوات؛ يبقى زر التثبيت في نسخة الويب كما كان.

توضح الخصوصية أن الحسابات محلية، وأن تفضيلات التقييم تُحفظ على الجهاز، وأن Google قد تعالج بيانات الإعلانات عند تفعيلها. لم نستخدم ادعاء أن التطبيق لا يخزن أي بيانات أو لا يحتاج الإنترنت مطلقًا، لأنه يخزن عداد التقييم وقد يعرض إعلانات. خيارات موافقة UMP القائمة محفوظة.

## العداد والتوقيت

- يسجل `calc_count` كل حساب ناجح مثبت بواسطة = أو CALC أو مساحة العمل المتقدمة، دون التعبير أو النتيجة.
- المعاينة والأخطاء واسترجاع السجل وضغط = مجددًا على النتيجة نفسها لا تُحتسب.
- بعد خمس عمليات يظهر التذكير إذا لم توجد نافذة HTML أخرى مفتوحة.
- «ذكرني لاحقاً» يكتب `rate_remind_at` بعد ثلاثة أيام من الوقت المحلي؛ تُراجع المهلة عند العودة للتطبيق وداخل الجلسة. عداد العمليات ليس مربوطًا بساعة خادم.
- نافذة التقييم تعرض خيارين فقط: التقييم الآن و«ذكرني لاحقاً». Escape أو لمس الخلفية يؤجلها ثلاثة أيام أيضًا ولا يوقفها نهائيًا. اختيار التقييم اليدوي أو التلقائي يكتب `rate_done=1`؛ لا يمكن للتطبيق التأكد أن المستخدم أكمل تقييمًا فعليًا. العلامات المحفوظة من الإصدارات السابقة تبقى محترمة.
- حذف بيانات التطبيق أو بيانات الموقع يمسح هذه التفضيلات. عند تعطل التخزين تظل الحسابات سليمة.

## وجهة الرابط

وجهة أزرار التقييم هي Google Play للمعرّف الرسمي `calces991.calculator`: رابط Android هو `market://details?id=calces991.calculator` مع بديل الويب `https://play.google.com/store/apps/details?id=calces991.calculator`.

الويب يفتح الرابط في نافذة مستقلة؛ Android يستخدم Intent VIEW خارجيًا، دون فتح الموقع داخل محرر الحاسبة. طريقة الجسر لا تقبل روابط أو intents اعتباطية من JavaScript.

## التفاعل والتحقق

النوافذ تستخدم HTML dialog في الطبقة العليا، مع تمرير داخلي وحد ارتفاع متجاوب، وإغلاق بخيارات النافذة أو Escape أو لمس الخارج. يحفظ المحرر موضعه، ويراقب منطق الإعلان الحالي فتح dialog لإخفاء البانر عند تفعيل الإعلانات. لا تتكدس نافذة التقييم فوق نافذة الخصوصية أو السجل.

اختبارات الوحدة تغطي الحد الخامس والمهلة والإغلاق والبيانات التالفة والتخزين المحظور. اختبارات Chromium الإنتاجية تغطي لمس نافذة الخصوصية وملاءمة الشاشة الرأسية والأفقية وموضع المحرر والوجهة الفعلية للرابط وتجاهل المعاينة والأخطاء والاسترجاع. هذه ليست محاكاة لجهاز Android فعلي أو تأكيدًا لعمل حساب AdMob.
