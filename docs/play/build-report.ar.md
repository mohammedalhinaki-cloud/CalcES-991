# نتيجة تجهيز Android — نسخة مراجعة وليست رفعًا نهائيًا

- الاسم الحالي ومعرّف الحزمة: CalcES 991 - حاسبة علمية / `com.mohammedalhinaki.studytools.calculator`، الإصدار 1.0.0 ورمز الإصدار 1.
- Android: min API 24، target/compile API 36، JDK 21، Gradle 8.14.3، AGP 8.13.0، System WebView 107+.
- نجحت مهام `assembleDebug` و`bundleRelease` و`lintDebug`.
- Android Lint: صفر أخطاء وثلاثة تنبيهات غير مانعة: إصدار GMA أحدث متاح، وموردَا config.xml وAppTheme.NoActionBar اللذان يراجعان من التوليد/الاعتمادات. لم تُعطّل فحوص Lint لإخفائها.
- نجح TypeScript والبناء و121 اختبار وحدة و33 اختبار متصفح على مخرجات الإنتاج.
- اختبارات الإعلان تستعمل SDK وهميًا للتحقق من الموافقة والحجز والكتم والإخفاء ومعرّفات الاختبار، وتختبر التخطيط بحجمي بانر 50 و90dp دون تغطية الأزرار. لم تُعرض إعلانات حقيقية في الاختبارات.
- APK يحتوي عشرين خطًا محليًا وعامل الحساب ولا يحمّل واجهة التطبيق من remote server. لا يتضمن مكتبات .so خاصة به. لم يُختبر تشغيل APK أو UMP/AdMob فعليًا على هاتف Android.
- APK موقّع بمفتاح التطوير المعتاد؛ ليس مفتاح رفع متجر. AAB غير موقعة، وتفعيل الإعلان الحقيقي في release معطّل افتراضيًا.
- لم تُنشأ مفاتيح توقيع إنتاج أو كلمات مرور للناشر، ولم يُرفع تطبيق إلى Google Play ولم يُنشر تحديث إلى Cloudflare في هذه المهمة.

## ما يتبقى من الناشر

اعتماد الاسم ومعرّف الحزمة والجمهور، وإضافة بريد الدعم وسياسة خصوصية نهائية منشورة. لتفعيل الإعلان يحتاج AdMob App ID وBanner Unit ID وإعداد UMP وربط app-ads.txt، ثم توقيع AAB بمفتاح رفع يملكه الناشر. يُختبر APK على جهاز فعلي ونسخة موقعة من Internal testing قبل الإنتاج، وتُستكمل إقرارات Play وفق إعدادات النسخة.

التفاصيل في [دليل النشر](README.ar.md). شغّل `npm run android:check-release` بعد ملء إعداداتك؛ فشل هذا الفحص حاليًا متوقع لغياب بيانات الناشر والتوقيع، وليس فشلًا لبناء APK/AAB.
