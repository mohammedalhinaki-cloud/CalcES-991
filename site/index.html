ما الذي يحتويه

محاكاة على مستوى التعليمات مع عدّ دورات دقيق

CPU

نواة nX‑U8/100 كاملة

المجموعة الموثقة كاملة بأعلام C/Z/S/OV/HC دقيقة، بنوك المقاطعات بثلاثة مستويات، وبادئة DSR وعقوبة [EA+] للناقل.

MMU

ذاكرة بنكية

نافذة ROM، ذاكرة RAM، مساحة SFR، VRAM ثقبًا-بثقب، وصفحتا كود بانعكاسbankي كما في الآلة الحقيقية.

PERIPH

طرفيات مربوطة

وحدة مقاطعات، مؤقتان يُغذّيان بالدورات، مسح لوحة مفاتيح 7×8، وتحكم LCD — عبر إرسال SFR حقيقي بأثر جانبي.

GUI

واجهة SDL2 + ImGui

شاشة LCD حية، لوحة مفاتيح قابلة للنقر، ولوحات تصحيح: السجلات، المفكك، الذاكرة، والطرفيات — مع تحكم تشغيل/خطوة.

البناء والتشغيل

terminal — linux / windows
# build and run the test suite
$ git clone https://github.com/mohammedalhinaki-cloud/Study-tools.git
$ cmake -S Study-tools -B build -DCMAKE_BUILD_TYPE=Release
$ cmake --build build --parallel
$ ctest --test-dir build --output-on-failure

# GUI needs libsdl2-dev; supply a ROM you dumped yourself
$ ./build/u8gui --rom rom.bin --steps-per-frame 50000

# headless run: registers + LCD frame dump
$ ./build/u8emu --rom rom.bin --steps 1000000 --regs --vram frame.raw

ملاحظة قانونية

لا يوزّع هذا المشروع أي نظام ثابت

المشروع لا يتضمن ولا يوزّع أي ثِبات (ROM) من كاسيو. لتشغيل المحاكي يجب أن توفر تفريغ ROM خاصًا بك قانونيًا (من آلة تملكها أو من نسخة برنامج كاسيو الرسمي الذي رخّصته). كاسيو والأسماء التجارية علامات مسجلة لشركة Casio Computer Co., Ltd.
