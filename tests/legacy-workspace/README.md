# اختبارات واجهة مساحة العمل السابقة

هذه اختبارات الواجهة التي كانت تستعمل مساحة العمل العامة ونوافذ MODE وSETUP وأزرار «احسب» والشريط الإضافي. أُرشفت، ولم تُحذف، لأن المستخدم طلب صراحةً في 29 أكتوبر 2026 حذف مساحة العمل بالكامل من الشكلين واستعمال شاشة LCD وحدها.

لم تعد توقعات ظهور مساحة العمل أو الأدلة أو الأزرار الإضافية متطلبات صحيحة. اختبارات النظام المدمج الحالي موجودة في `tests/e2e/device.spec.ts`، واختبارات محرك الحساب وتحوّلات الحالة والقوالب العددية تحت `src/tests/`. لا يُستعاض عن حسابات الواجهة القديمة بنتائج وهمية؛ تعاد تغطية الإدخال والقوالب والأوضاع والتبديل داخل شاشة الجهاز.
